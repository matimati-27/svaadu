# Turning on the Hindi site (`?lang=hi`) — about 30 min

What changed in the repo:

| File | Status | Why |
|---|---|---|
| `strings.js` | **new** | Every on-screen line, one block per language (`te`, `hi`), same keys in the same order. Edit text here, not in `index.html`. |
| `index.html` | replaced | Reads all text from `strings.js` instead of having Telugu written into it. |
| `apps-script/Code.gs` | replaced | Writes a blank into the old "School medium" column so the columns after it don't shift. |
| `questions/hi/q1.m4a … q5.m4a` | **you add these** | Your Hindi question recordings. |
| `config.js` | unchanged | Already lists the Hindi questions. |

---

## 1. Copy the files into your repo (2 min)
Copy `index.html`, `strings.js`, `apps-script/Code.gs` and the two `.setup-*.md` files over the ones in your local `svaadu/` folder. Don't commit yet.

## 2. Record the 5 Hindi questions (10 min)
Same way as the Telugu ones: phone voice recorder, quiet room, one file per question, saved as **.m4a**. Ask them the way you asked the Telugu ones; whoever of you two sounds more natural in Hindi should record. Suggested wording (matching your English list):

1. आज दोपहर के खाने में आपने क्या खाया? वो कैसे बनाया?
2. आपने आख़िरी बार किसी रेस्टोरेंट या होटल से क्या मँगाया  था? उसमें क्या-क्या चीज़ें डलती हैं?
3. यदि मैं अभी बाज़ार या मंडी जाऊँ, तो आपकी रसोई के लिए क्या-क्या ला सकता हूँ?
4. हलवा बनाने के लिए क्या-क्या चाहिए होता है?
5. अभी जो वीडियो आपने देखा, उसमें जो बना, वो अपने शब्दों में समझाइए — ऐसे, जैसे आप मुझे सिखा रहे हों जिसने ये कभी नहीं बनाया।

While recording, don't name any ingredient, utensil or dish in the question (not even the dish in the video). Whatever word you use for it, Hindi or English, is a word respondents are likely to repeat back.

Rename them `q1.m4a` … `q5.m4a` and put them in `questions/hi/`.

## 3. Update the Google script (5 min) — do this before sending any Hindi link
1. Open **script.google.com** → your project.
2. Select everything in `Code.gs`, delete it, paste the whole new `apps-script/Code.gs`, press **Ctrl+S**.
3. **Deploy → Manage deployments** → the pencil ✏️ on your existing deployment → *Version:* **New version** → **Deploy**.
   - Do **not** use *Deploy → New deployment*: that makes a new URL, and `config.js` would then point at the old one.
4. The URL stays the same, so `config.js` needs no change.

## 4. Push (2 min)
```bash
git add index.html strings.js apps-script/Code.gs questions/hi/ .setup-hindi.md .setup-instructions.md
git commit -m "Add Hindi site; move on-screen text to strings.js"
git push
```
Wait for the green tick under the repo's **Actions** tab (about 1 min).

## 5. Test both languages (10 min)
On your phone, in a **fresh incognito tab each time**:
- `https://matimati-27.github.io/svaadu/?lang=hi` — go all the way through.
- `https://matimati-27.github.io/svaadu/?lang=te` — go all the way through (the page code changed, so check Telugu too).

Then in the Sheet:
- *Respondents*: two new rows, Language `hi` and `te`, with Age, Gender, etc. under the right headings, School medium blank, and **Answers received = 5**.
- *Recordings*: 10 new rows; the Hindi files are named `R-XXXXXX_hi_Q01_…`.

Delete your test rows and the two test folders in Drive afterwards.

## 6. Share the data with your teammate (1 min)
The repo is shared, but the recordings live in **your** Google Drive. Share the folder **Kitchen Talk Recordings** and the Sheet **Kitchen Talk Responses** with your teammate (Share → Editor).

---

### Editing text later
All text is in `strings.js`. Lines marked `(EN only)` are still English in both languages; to add Telugu/Hindi, append ` // …` to the line in **both** blocks so the two sites stay mirrored. Values marked `[html]` may contain `<br>` / `<b>`; elsewhere a `<br>` would show up as literal text.

### Sheet values
Gender and cooking-experience answers are now saved in plain English (`Woman`, `More than 15 years`) whatever the site language, so Telugu and Hindi rows can be compared directly. Telugu responses that came in **before** this update say `Female // మహిళ` etc.; use *Edit → Find and replace* in the Sheet to make them match.
